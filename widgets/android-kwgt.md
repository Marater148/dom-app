# Виджет «Дом» для Android (KWGT)

Нужно приложение **KWGT Kustom Widget Maker** из Google Play. Чтобы поставить виджет на экран, KWGT попросит **KWGT Pro** (разовая покупка, около $3–5).

## 1. Поставьте пустой виджет
Долгое нажатие на пустом месте экрана → **Виджеты** → **KWGT** → размер **4×2** → перетащите на экран → нажмите на него → **Создать пустой** (или «+»).

## 2. Одна переменная с адресом данных
Вкладка **Глобальные** (Globals) → **+** → тип **Текст** → имя `u` → значение (одной строкой, `КЛЮЧ` замените на ключ виджета):

```
ССЫЛКА_НА_EXEC?action=summary&who=marat&key=КЛЮЧ
```

Ключ: Apps Script → ⚙ **Настройки проекта** → **Свойства скрипта** → значение `WIDGET_KEY`.

## 3. Фон
Вкладка **Фон** (Background): цвет `#121418`, прозрачность ~85%, скругление углов `24`.

## 4. Текст
Добавьте **Группу (Stack Group)**, вертикальную, отступы 14. Внутрь — элементы **Текст**, в поле «Текст» вставьте формулу:

| Строка | Формула | Размер | Цвет |
|---|---|---|---|
| Заголовок | `Дом` | 14, жирный | `#B5A8E8` |
| Подпись | `Осталось в месяце` | 11 | `#B4B8C0` |
| Бюджет | `$$wg(gv(u), json, .budgetLeftUsd)$` | 28, жирный | `#A8D5A2` |
| Задачи | `Задач: $wg(gv(u), json, .tasksCount)$ · купить: $wg(gv(u), json, .shopCount)$` | 13 | `#ECEAE4` |
| Ужин | `Ужин: $wg(gv(u), json, .dinner)$` | 13 | `#ECEAE4` |
| Платёж | `$wg(gv(u), json, .nextPayment.day)$-го: $wg(gv(u), json, .nextPayment.name)$` | 12 | `#F2B880` |

Если вместо знака `$` в строке «Бюджет» ничего не видно — замените формулу на `$wg(gv(u), json, .budgetLeftUsd)$ USD`.

## 5. Нажатие открывает приложение
Выделите группу → вкладка **Касание** (Touch) → **Открыть ссылку** → `https://marater148.github.io/dom-app/`

## 6. Сохранить
Иконка дискеты вверху справа. Данные обновляются сами раз в 15–60 минут; чтобы проверить сразу — в редакторе меню ⋮ → **Обновить**.
