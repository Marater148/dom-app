# Виджет «Дом» для Android (KWGT)

Понадобится приложение **KWGT Kustom Widget Maker** из Google Play. Бесплатной версии хватает, чтобы собрать и проверить виджет в редакторе; чтобы поставить его на экран, KWGT может попросить **KWGT Pro** (разовая покупка, пара долларов).

Везде ниже замените `ССЫЛКА` на ссылку веб-приложения (`https://script.google.com/macros/s/…/exec`) и `КЛЮЧ` на ключ виджета из Apps Script.

Адрес данных для виджета (одна строка):

```
ССЫЛКА?action=summary&key=КЛЮЧ&who=marat
```

## Сборка (5–7 минут)

1. Долгое нажатие на пустом месте главного экрана → **Виджеты** → **KWGT** → размер **4×2** → поставьте на экран.
2. Нажмите на пустой виджет — откроется редактор. Выберите **Создать пустой**.
3. Вкладка **Фон** (Background): тип — цвет, цвет `#121418`, скругление углов ~24.
4. Добавьте элемент **Overlap Group** (Группа), внутри неё — пять элементов **Текст** (Text) сверху вниз. В каждом в поле **Текст** вставьте формулу:

| Элемент | Формула | Размер | Цвет |
|---|---|---|---|
| Заголовок | `Дом` | 14 | `#B5A8E8` |
| Подпись | `До лимита месяца` | 11 | `#8C9099` |
| Остаток бюджета | `$wg("ССЫЛКА?action=summary&key=КЛЮЧ&who=marat", json, .budgetLeftUsd)$ USD` | 28, жирный | `#A8D5A2` |
| Задачи | `Задач сегодня: $wg("ССЫЛКА?action=summary&key=КЛЮЧ&who=marat", json, .tasksCount)$ · купить: $wg("ССЫЛКА?action=summary&key=КЛЮЧ&who=marat", json, .shopCount)$` | 13 | `#ECEAE4` |
| Ужин | `Ужин: $wg("ССЫЛКА?action=summary&key=КЛЮЧ&who=marat", json, .dinner)$` | 13 | `#ECEAE4` |

   По желанию шестая строка — ближайший платёж:
   `Платёж $wg("ССЫЛКА?action=summary&key=КЛЮЧ&who=marat", json, .nextPayment.day)$-го: $wg("ССЫЛКА?action=summary&key=КЛЮЧ&who=marat", json, .nextPayment.name)$`

5. Нажмите на группу → вкладка **Касание** (Touch) → **Открыть ссылку** → адрес приложения (например `https://dom-maria-marat.vercel.app`). Теперь нажатие на виджет открывает «Дом».
6. Сохраните (иконка дискеты вверху справа) и выйдите.

KWGT обновляет данные из интернета сам (обычно раз в 15–60 минут, зависит от настроек экономии батареи). Если цифры не появляются сразу — подождите минуту или откройте редактор и нажмите «Обновить».

## Если не хочется KWGT

Откройте приложение «Дом» в Chrome → меню ⋮ → **Установить приложение**. Долгое нажатие на иконке «Дом» покажет быстрые действия **«Добавить трату»** и **«Список покупок»** — их можно вытащить на экран как отдельные ярлыки.
