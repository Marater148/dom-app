# Виджет «Дом» для Android (KWGT)

Показывает: задачи на сегодня, что на ужин, список покупок — на фоне фото из приложения.

Нужно приложение **KWGT Kustom Widget Maker** из Google Play. Чтобы поставить виджет на экран, KWGT попросит **KWGT Pro** (разовая покупка, около $3–5).

## 1. Пустой виджет
Долгое нажатие на пустом месте экрана → **Виджеты** → **KWGT** → размер **4×2** → перетащите на экран → нажмите на него → **Создать пустой** (или «+»).

## 2. Переменная с адресом данных
Вкладка **Глобальные** (Globals) → **+** → тип **Текст** → имя `u` → значение одной строкой (`КЛЮЧ` замените на ключ виджета):

```
ССЫЛКА_НА_EXEC?action=summary&who=marat&key=КЛЮЧ
```

Ключ: Apps Script → ⚙ **Настройки проекта** → **Свойства скрипта** → значение `WIDGET_KEY`.

## 3. Фото на фоне
Вкладка **Фон** (Background): цвет `#121418`, скругление углов `24`.

Вкладка **Элементы** → **+** → **Изображение** (Image):
- **Растровое изображение** (Bitmap) → нажмите на поле → значок формулы → вставьте `$wg(gv(u), json, .bg)$`
- Ширина = на всю ширину виджета, режим **Обрезка/Заполнить** (Fit: Crop/Center crop)
- Скругление углов `24`

Сверху добавьте **Фигура** (Shape) → прямоугольник на весь виджет, цвет `#0E1014`, прозрачность **60%**, скругление `24`. Это затемнение, чтобы текст читался.

Фото меняется при каждом обновлении данных (раз в 15–60 минут).

## 4. Текст
Добавьте **Группу (Stack Group)** — вертикальную, отступы 14. Внутрь — элементы **Текст**:

| Строка | Формула | Размер | Цвет |
|---|---|---|---|
| Заголовок | `Дом` | 14, жирный | `#B5A8E8` |
| Подпись | `СЕГОДНЯ` | 9, жирный | `#B4B8C0` |
| Задачи | `$wg(gv(u), json, .tasksText)$` | 13, макс. строк 5 | `#ECEAE4` |
| Подпись | `УЖИН` | 9, жирный | `#B4B8C0` |
| Ужин | `$if(wg(gv(u), json, .dinner)="", "не задан", wg(gv(u), json, .dinner))$` | 13, жирный | `#ECEAE4` |
| Подпись | `КУПИТЬ` | 9, жирный | `#B4B8C0` |
| Покупки | `$wg(gv(u), json, .shopText)$` | 13, макс. строк 2 | `#ECEAE4` |

Между блоками — отступ 8 (элемент **Пробел** или отступ сверху у подписи). Для читаемости на фото у текстов включите **Тень** (Shadow): чёрная, размытие 3.

## 5. Нажатие открывает приложение
Выделите группу → вкладка **Касание** (Touch) → **Открыть ссылку** → `https://marater148.github.io/dom-app/`

## 6. Сохранить
Иконка дискеты вверху справа. Чтобы проверить сразу — в редакторе меню ⋮ → **Обновить**.
